# 01. Концепция

## Главная мысль

Плейс — не концертный зал, а машина для производства контента. Концерт раз в неделю даёт
событие и пик внимания, а открытая сцена в остальное время даёт постоянный поток чужих
перформансов, из которых получаются вертикальные клипы. Группа в этой схеме не только
выступает, но и владеет площадкой, на которой выступают другие.

Из этого следует приоритет, который легко потерять: **сначала работает открытая сцена, потом
делается большое шоу.** Открытая сцена держит DAU и монетизацию между событиями; концерт без
неё даёт один пик и пустой стадион на следующий день.

## Три слоя плейса

1. **Событийный слой.** Анонсированный концерт по расписанию. Редкий, подготовленный, с
   таймлайном света и пиротехники. Задача — пик онлайна, повод для анонсов и материал для
   нарезки.
2. **Повседневный слой.** Открытая сцена: за 20 R$ игрок получает слот 60–90 секунд, свет,
   эффекты, своё имя на экране стадиона и зал, который может ему хлопать. Задача — удержание,
   выручка и бесконечный UGC.
3. **Съёмочный слой.** Режим съёмки с вертикальной рамкой, выключенным интерфейсом и
   операторскими планами. Задача — чтобы любой игрок мог снять красивый клип без навыков,
   а группа получала поток готового контента.

## Петля вовлечения

```
TikTok (клип со сцены)
      -> переход в плейс
      -> первый опыт: зал, свет, кто-то выступает
      -> покупка выхода на сцену (20 R$)
      -> свой перформанс, свой клип в режиме съёмки
      -> публикация клипа с упоминанием плейса
      -> новые игроки
```

Параллельная петля вокруг события:

```
анонс концерта (Experience Event + TikTok)
      -> напоминание в день шоу
      -> концерт, пик онлайна
      -> нарезка 3–5 клипов из одного шоу
      -> анонс следующего концерта в конце клипа
```

Обе петли сходятся в одном месте: трек на стриминге. Внутри плейса песня звучит целиком,
на экранах стадиона — название релиза, после концерта — экран с напоминанием, где слушать.

## Позиционирование для группы

Группа виртуальная, значит у неё нет ограничения «тур стоит денег». Плейс заменяет и сцену, и
клип, и площадку для фанатов. Три вещи, которые он даёт реальному проекту:

- **Площадка вместо аренды.** Еженедельное живое событие без затрат на зал и свет.
- **Контент-завод.** Один концерт превращается в неделю публикаций, а чужие перформансы на
  открытой сцене дают контент каждый день.
- **Актив, а не расход.** Открытая сцена, VIP и мерч для аватаров приносят Robux, то есть
  плейс частично или полностью финансирует собственное развитие и продвижение.

## Чего сознательно не делаем

- **Не делаем «ещё одну игру».** Никаких уровней, боёв и прокачки. Любая механика, которая не
  ведёт к перформансу или к клипу, вырезается.
- **Не делаем единый концерт на всех.** В Roblox один сервер держит ограниченное число игроков,
  поэтому масштаб достигается шардами и локальной массовкой, а не попыткой собрать всех в одном
  инстансе (см. [07-performance-limits.md](07-performance-limits.md)).
- **Не делаем сложный аватар-кастомайзер.** Образ участников группы — это их риг и мерч,
  а не редактор.

## Ключевая метрика на старте

Доля визитов, завершившихся выходом на сцену или снятым клипом. Это единственная метрика,
которая одновременно означает выручку, удержание и приток новых игроков. Остальное
(см. [10-metrics.md](10-metrics.md)) — диагностика.
